Instruction for cloning and running app
----------------------------
Run the following commands in termnial

# Clone
...
git clone https://github.com/Schnell8/mvc.git
...

# Composer install
...
composer install
...

# Npm install
...
npm install
...

# Run app
...
php -S localhost:8888 -t public
...

# Open browser
Open up localhost:8888 in browser
